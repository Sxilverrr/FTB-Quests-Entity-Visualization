This is an unofficial add-on mod for FTB Quests.

This mod replaces the boring spawn‑egg icon in a kill task with the actual entity rendered live in 3D.

Each task has its own size, X/Y offset, and rotation options, which are added into the FTB Quests task editor.

Kill and observation tasks that target an entity type tag cycle through every entity in that tag.

Any entity display can hold several NBT variants and cycle through them.

Any entity display can have a name tag above it, which works well for putting names over player displays.

Config:
- Toggle spin, idle, and walk animation defaults.
- Spin speed multiplier
- Camera tilt
- Full‑bright rendering toggle
- Entity tag cycling toggle and cycle speed (the speed also applies to NBT variant cycling)
